# CPokemonBL
ccClub2025Fall Final Project


https://cpokemonbl.onrender.com

## 簡介
本工具結合中職球員與寶可夢數據，以寶可夢的概念來對應球員強度，讓球迷可以藉由一個球員是超夢、噴火龍或鯉魚王的方式，快速判斷一名球員的強度。

## Preface
2024台灣在12強奪冠後，新球迷的人數大幅增加，但對新球迷而言，不容易馬上判斷一名球員的程度。

為了讓新球迷在看球時可以快速上手，我們想到用寶可夢的概念來介紹球員，於是就有了這個專案，透過球員與寶可夢能力值的配對，讓每一位球員可以配對到一隻在實力上最接近的寶可夢，以此幫助球迷快速入坑。

## 數據對應
| 球員 | 寶可夢 | 說明 |
| --- | --- | --- |
| PA | Hp | 上場打擊多少次是最直接反映選手耐力的指標，對應的就是寶可夢 HP |
| wOBA | Atk | wOBA 是目前棒球統計界中公認最能夠兼顧「精準呈現球員攻擊數據」及「只用一個數字直觀呈現」的指標，那當然就是對應寶可夢的攻擊值 |
| OBP | Def | 對打者來說，面對投手的投球攻擊，最優先目的就是不出局，上壘率就是不出局的能力，故對應的就是寶可夢的防禦值 |
| ISOP | SA | 有長打能力的打者永遠是最有魅力的，純長打率相較其他基礎數據是最能夠直接反映打者長打能力的指標，對應寶可夢的特攻值 |
| K% | SD | 對打者來說，被三振仍然是所有出局方式中，最沒有價值的一種形式，在打擊率、上壘率、長打率完全相同的兩位球員，被三振率較低的球員仍然有較高的攻擊貢獻，因此不容易被三振可以視為是一種特殊防禦力 |
| SB | Sp | 盜壘 = 速度 BJ4 |

## 網頁功能簡介與說明
- 搜尋：輸入想查詢的球員中文姓名，點選搜尋即可跳至對應頁面
- 直接選擇選手：點選六隊球員名稱即可跳至對應頁面
  

- 備註1：本網站目前僅納入野手資料，且為避免PA過低導致出現極端值，本網站目前只納入PA>=120的球員
- 備註2：為配合呈現，K%以（100-K%）呈現，數值越高，表示該球員越不易被三振
